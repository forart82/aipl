Project Manifesto & Core Mission

AIPL (AI-Programming Language) is the first systems and application programming language co-designed from the tokenomics level up for artificial intelligence coding agents and dual-backend execution (TypeScript/React 19 for web/edge and parallel C99 shards / Native ELF64 / WebAssembly for bare metal).

Core Architectural Tenets

  • Empirical Tokenomics Optimization: Subword-aligned syntax calibrated against SentencePiece 256k vocabularies, achieving 60%+ token reduction.
  • Dual-Backend Early Bifurcation: Single canonical HIR lowering seamlessly to native C99/Wasm or idiomatic TypeScript 5.x.
  • Anti-GC Flat-Stride Memory: Structure of Arrays (SoA) memory layouts and regional bump arenas with zero garbage collector pauses.
  • Machine-Tractable Agent Tooling: Structured JSON error diagnostics (diagnostic-v1.json), AST diff auto-repairs, and surgical symbol splicing.

Language Specification Overview

AIPL combines sound bidirectional type checking, strict boolean invariants, explicit error handling via Option[T] and Result[T, E], and Design-by-Contract verification.

module examples.hello
import * from "std/prelude"

pub fn safeDivide(numerator: int, denominator: int): int:
  req: denominator != 0
  ens: retVal * denominator <= numerator
  ret numerator / denominator

pub fn main(): int:
  let quotient = safeDivide(100, 5)
  println("Result: " + str(quotient))
  ret 0

Grammar & Syntax Guide

AIPL enforces strict, machine-tractable syntax invariants designed for single-token evaluation under subword tokenizers:

  • 2-Space Indentation Offside Rule: Blocks begin with : followed by an indented body indented by exactly 2 spaces. Tabs and curly braces are prohibited.
  • Mandatory Identifier Casing: Variables, functions, and members use camelCase. Structs, enums, and types use PascalCase. Underscores are banned.
  • No Semicolons: Statements are strictly newline-delimited.
  • Operator Precedence: 11 distinct levels from lowest (logical or, and) to highest (primary member access and postfix operators).

Consult docs/GRAMMAR_AND_SYNTAX.md for the exhaustive formal EBNF grammar specification.

Compiler Architecture & Subsystems

The self-hosted compiler is organized into 11 modular subsystems in compiler/*.aipl:

  • Lexer & Tokens (lexer.aipl) — Parallel offside lexer with 2-space virtual indent tracking.
  • Pratt Parser (parser.aipl) — AstArena-allocated AST construction with error-resilient recovery.
  • Symbol Resolver (resolve.aipl) — Module imports, lexical scope resolution, and shadowing checks.
  • Bidirectional Typechecker (types.aipl) — Bidirectional Hindley-Milner type checking without implicit coercion.
  • Embedded SMT Solver (smt.aipl) — Proves req: and ens: contract invariants via Octagon DBM closure.
  • Canonical HIR (hir.aipl) — Mid-level intermediate representation with early bifurcation.
  • Code Generators — codegen_c_or_ir.aipl (parallel C99), codegen_ts.aipl (TypeScript/React 19), codegen_wasm.aipl (Wasm).

Consult docs/ARCHITECTURE.md for the complete compiler pipeline manual.

Anti-GC Flat-Stride Memory Model

AIPL eliminates tracing garbage collection pauses through a deterministic 3-tier memory model:

  • Tier 1: Regional Bump Arenas (with arena:) — Scoped stack bump allocations reclaimed in bulk at scope exit with zero fragmentation.
  • Tier 2: Generational Object Pools — Fast slot reuse with ABA-safe 64-bit generation tags for long-lived game entities.
  • Tier 3: Slabs & Ring Buffers — Fixed-size block allocators and circular buffers for high-throughput streaming.

Consult docs/MEMORY_MODEL.md for memory layouts, cache benchmarks, and leak detection.

Diagnostics Schema & Autonomous Self-Repair

AIPL emits single-root machine-readable JSON diagnostics following diagnostic-v1.json:

  • E1xx — Lexical & Syntactic Errors (indentation, forbidden keywords, syntax violations).
  • E2xx — Type & Resolution Errors (type mismatches, undeclared variables, mutability errors).
  • E3xx — Contract & SMT Verification Errors (precondition violations, postcondition refutations).

Each diagnostic includes exact byte spans, SHA-256 source hashes, and pre-calculated unified diff candidate repairs for autonomous self-healing via aipl fix. Consult docs/DIAGNOSTICS_SCHEMA.md.

Architecture Decision Records (33 ADRs)

All architectural decisions are documented as living records under docs/ADR/ and indexed in docs/ADR/INDEX.md.

ADR-0001: Dual-Backend Early Bifurcation at Canonical HIR

Bifurcates Canonical HIR into TypeScript/React 19 for web/edge and C99/Native/Wasm for bare metal, preserving language ergonomics on both targets.

ADR-0002: Gemini 256k SentencePiece Tokenomics & camelCase Invariant

Eliminates token fragmentation via camelCase identifiers, 2-space indentation, and subword-aligned keywords, achieving 60%+ token savings.

ADR-0004: Anti-GC Flat Stride Memory & Task-Local Regional Arenas

Guarantees 100% 64-byte L1d cache utilization via Structure of Arrays (SoA) layout and scoped regional bump allocators with zero GC spikes.

ADR-0011: Lightweight Embedded SMT Refinement Solving (QF-LIA & EUF)

Proves req:/ens: contracts, eliminates bounds checks, and refutes arithmetic errors at compile time.

ADR-0029: 100% Pure AIPL Self-Hosting, C99 Backend & 3-Stage Bootstrap

Establishes language sovereignty through a 100% self-hosted compiler and deterministic 3-stage bootstrap fixed-point guarantee (sha256(stage2.c) == sha256(stage3.c)).

ADR-0034: Android NDK NativeActivity & Pure-C99 Runtime Integration

Architects native Android arm64 support using NativeActivity, linking with the Android NDK runtime without Java or Gradle dependencies.

ADR-0035: Mobile In-Memory VFS, File Watcher & TCP Live-Reload Sync

Specifies the virtual filesystem, mobile change polling, TCP packet protocol, and on-device HUD for interactive live reload.

ADR-0036: Pure-AIPL Standalone Signed APK Container & Zero-Toolchain Distribution

Defines end-to-end binary AXML generation, APK Zip packaging, and APK Signature Scheme v2 signing natively in pure AIPL.
